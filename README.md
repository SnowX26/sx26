# Mustafa PS4 PS5 Exploit Host

A web-based GoldHEN exploit hosting service for PS4 firmware versions 7.00-13.00. This repository provides a fully automatic jailbreak delivery system that detects the PS4's firmware version and serves the appropriate exploit payload.

## What This Is

This is a self-hosted web server that delivers the GoldHEN v2.4b18.10 jailbreak exploit to PS4 consoles. When accessed from a compatible PS4, the server automatically detects the firmware version and serves the appropriate exploit chain for that firmware, enabling unrestricted access to the console.

### Stack

- **Language(s):** JavaScript (HTML/CSS/JS)
- **Runtime:** Static web server / Browser-based
- **Key Libraries:** HTML5 ApplicationCache API for offline exploit delivery
